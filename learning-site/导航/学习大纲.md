# Linux 内核、驱动与相机开发学习大纲

先学能脱离本板回答的基本机制，再把它迁移到 RV1126B。八卷 84 章沿用原编号，阶段顺序为开发基础 → 应用与驱动接口 → 内核与设备模型 → 采集及产品 → 诊断与面试。卷三、卷四也可作为独立的内核和驱动面试索引。

每章正文沿同一结构落地：通用问题、对象关系、注册/执行/退出调用链、关键分支、源码验证、本节复盘、本板对照。先用自己的话回答本页问题，再到正文核对；项目里的硬件结论以证据为准。

| 进阶方向 | 优先章节 | 读完能回答 |
| --- | --- | --- |
| 内核与系统编程 | 卷二、卷三 | 为什么线程已唤醒却迟迟未执行，何时缺页，为什么删除文件后空间不释放 |
| BSP 与驱动 | 卷二、卷四、卷五 | 怎么由设备树找到资源提供者，probe 如何绑定、回退和释放 |
| 相机与视频 | 卷五至卷七 | 为什么能读 ID 却拿不到图，如何解释格式、队列、背压和画质变化 |
| 性能与工程答辩 | 卷三、卷八 | 怎样区分相关和因果，并为一次优化提供对照和回归证据 |

八卷 84 章已按分章计划整理并完成本地正文验收。下方每章可进入正文或独立小节。各章标注实验环境与实测范围。需要现场测试的项目继续按各章条件验证。
